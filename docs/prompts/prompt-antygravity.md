## 3. Objetivo principal

Desarrollar un **método matemático capaz de simular la evolución fisiológica de distintos órganos humanos en condiciones espaciales**.

No quiero que los órganos sean únicamente modelos 3D estáticos que cambian de color cuando aparece una anomalía.

Quiero que exista una capa matemática independiente que permita:

1. Representar el estado fisiológico de cada órgano.
2. Simular su evolución a través del tiempo.
3. Representar cambios asociados a condiciones ambientales y fisiológicas espaciales.
4. Identificar patrones y desviaciones respecto a un estado de referencia.
5. Generar resultados que puedan visualizarse sobre los órganos correspondientes.
6. Mantener trazabilidad sobre las variables, ecuaciones, parámetros y fuentes utilizadas.

El alcance es exclusivamente el **simulador fisiológico de órganos**.

No debes desarrollar ni modificar otros subsistemas de LIGHTMINUTE.

---

## 4. Investigación matemática y fisiológica previa

Antes de escribir código, investiga y determina qué modelos matemáticos son apropiados para representar la evolución fisiológica de los órganos.

Evalúa principalmente:

- Sistemas de ecuaciones diferenciales ordinarias (ODE).
- Modelos dinámicos de espacio de estados.
- Modelos compartimentales.
- Modelos fisiológicos basados en variables de entrada y salida.
- Modelos híbridos cuando sea necesario combinar ecuaciones continuas y eventos discretos.

No selecciones un modelo simplemente porque sea fácil de programar. Justifica su elección según el fenómeno fisiológico que representa.

La formulación general puede partir de:

\[
\frac{dx_i(t)}{dt}=f_i(x_i(t),u(t),e(t),m(t),\theta_i)
\]

Donde:

- \(x_i(t)\): estado fisiológico del órgano o sistema.
- \(u(t)\): estímulos o condiciones fisiológicas, como actividad física, descanso, hidratación y alimentación.
- \(e(t)\): condiciones ambientales espaciales.
- \(m(t)\): contexto de la misión.
- \(\theta_i\): parámetros propios del modelo fisiológico.
- \(f_i\): función matemática que describe la evolución del sistema.

Esta expresión es un marco general, no una ecuación fisiológica validada. Debes formular las ecuaciones específicas de cada órgano a partir de evidencia científica.

### Condiciones espaciales que pueden considerarse

Evalúa la influencia de:

- Microgravedad.
- Gravedad parcial lunar.
- Exposición a radiación espacial.
- Cambios en la actividad física.
- Alteraciones del sueño.
- Cambios de hidratación.
- Condiciones ambientales de la cabina.
- Duración de la misión.

No asumas que todos estos factores afectan directamente a todos los órganos. Establece las relaciones fisiológicas justificadas por la literatura.

---

## 5. Órganos y sistemas que debe contemplar el modelo

Diseña el modelo de manera modular. Cada órgano o sistema debe tener su propio conjunto de variables, ecuaciones, parámetros y condiciones iniciales.

### 5.1. Sistema cardiovascular

Órganos y estructuras:

- Corazón.
- Aorta.
- Vasos sanguíneos.
- Venas yugulares.

Investiga y modela, cuando exista evidencia suficiente:

- Frecuencia cardíaca.
- Volumen sanguíneo.
- Distribución de fluidos.
- Respuesta cardiovascular a cambios gravitacionales.
- Adaptación cardiovascular.

### 5.2. Sistema nervioso y sensorial

Elementos:

- Cerebro.
- Ojos.
- Médula espinal.

Considera los fenómenos relacionados con:

- Adaptación vestibular.
- Orientación espacial.
- Cambios sensoriales.
- Respuesta neurológica a condiciones de microgravedad.

### 5.3. Sistema respiratorio

Elementos:

- Pulmones.

Evalúa:

- Ventilación.
- Intercambio gaseoso.
- Frecuencia respiratoria.
- Relación con la presión y composición atmosférica de la cabina.

### 5.4. Sistema renal y urinario

Elementos:

- Riñón izquierdo.
- Riñón derecho.
- Vejiga, si existe representación anatómica disponible.

Evalúa:

- Balance hídrico.
- Filtración renal, únicamente si existe una formulación justificable.
- Excreción.
- Cambios relacionados con la redistribución de fluidos.

### 5.5. Sistema digestivo y hepático

Elementos:

- Hígado.
- Estómago.
- Intestino delgado.
- Intestino grueso.

Evalúa qué fenómenos pueden representarse matemáticamente y cuáles necesitan datos que no están disponibles.

### 5.6. Sistema musculoesquelético

Elementos:

- Columna vertebral.
- Estructuras óseas y musculares, cuando exista representación disponible.

Considera:

- Pérdida o remodelación ósea.
- Desacondicionamiento muscular.
- Influencia de la carga mecánica.
- Respuesta al ejercicio.

### 5.7. Sistema reproductor

Elemento disponible:

- Útero.

No inventes un modelo fisiológico reproductivo si no existe suficiente evidencia o datos para justificarlo. Documenta qué sería necesario para desarrollarlo.

## 6. Requisitos del método matemático

Cada modelo fisiológico debe documentar obligatoriamente:

| Elemento | Descripción |
|---|---|
| Identificador | Código único del modelo |
| Órgano | Órgano o sistema representado |
| Fenómeno | Proceso fisiológico simulado |
| Variables de estado | Magnitudes que evolucionan |
| Variables de entrada | Estímulos y condiciones externas |
| Ecuaciones | Formulación matemática |
| Parámetros | Coeficientes y constantes |
| Unidades | Unidades físicas de cada variable |
| Condiciones iniciales | Estado de partida |
| Condiciones de frontera | Restricciones del modelo |
| Método numérico | Método para resolver las ecuaciones |
| Paso temporal | Intervalo de integración |
| Fuente científica | Referencia que respalda el modelo |
| Limitaciones | Qué no puede representar |
| Incertidumbre | Qué tan confiable es el resultado |

No introduzcas coeficientes arbitrarios para conseguir que la simulación parezca realista.

Si no existe un parámetro validado:

1. Identifica el parámetro como pendiente de calibración.
2. Busca una fuente científica que permita establecer un rango.
3. Si necesitas un valor provisional para una demostración, identifícalo como SIMULADO o ESTIMADO.
4. No lo presentes como un dato fisiológico real.

---

## 7. Detección de patrones fisiológicos

El simulador debe permitir observar cómo evolucionan las variables de los órganos y detectar cambios respecto a un estado de referencia.

Investiga la aplicación de métodos como:

- Análisis de tendencias.
- Media móvil.
- Desviación respecto a una línea base individual.
- Z-score, cuando se cumplan sus supuestos.
- EWMA.
- CUSUM.
- Análisis de variabilidad.
- Detección de cambios sostenidos.
- Comparación entre escenarios.

No es necesario aplicar todos los métodos a todos los órganos. Selecciona los apropiados para cada variable.

Distingue claramente:

- Variación fisiológica esperable.
- Cambio temporal.
- Desviación estadística.
- Anomalía de calidad de datos.
- Posible alteración fisiológica que requiere revisión.

Una anomalía estadística no equivale a una enfermedad ni a un diagnóstico médico.

---

|---|---|
| Cerebro | `brain.glb` |
| Corazón | `heart.glb` |
