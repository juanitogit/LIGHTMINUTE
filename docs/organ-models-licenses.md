# Licencias y Atribuciones — Modelos GLB de Órganos (`organs/`)

Este documento detalla las licencias de uso, autores, procedencia institucional, identificadores DOI y las directrices de atribución para todos los modelos 3D en formato GLB ubicados en la carpeta `organs/` del proyecto **LIGHTMINUTE**, descargados u originados a través de **NIH 3D** (National Institutes of Health) y el **Human Reference Atlas (HRA) / HuBMAP Consortium**.

---

## 1. Resumen de Licencia General

Todos los modelos anatómicos de referencia provienen de la **Human Reference Atlas (HRA) 3D Reference Object Library** y están publicados en **NIH 3D** bajo la licencia:

* **Licencia:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
* **Permisos:** Libertad para compartir, copiar, redistribuir, adaptar, remezclar y transformar el material para cualquier propósito, incluso comercial.
* **Condición obligatoria de la licencia:** Proporcionar la atribución adecuada, incluir un enlace a la licencia e indicar claramente si se realizaron modificaciones sobre los modelos originales.
* **Aviso de no aval:** La reutilización no implica que NIH, NLM, HRA o los autores respalden este software ni los análisis derivados.
* **Uso en LIGHTMINUTE:** Los modelos son mallas anatómicas de referencia tridimensional para visualización geométrica; no constituyen exploraciones médicas de pacientes reales ni dispositivos de diagnóstico.

## 4. Cita Institucional y de la Colección HuBMAP / HRA

Todos los modelos individuales forman parte del proyecto coordinado de la biblioteca de órganos de referencia de HuBMAP / Human Reference Atlas. Para citar la colección completa o dar crédito institucional en la documentación o interfaz de usuario:

> **Colección:** Human Reference Atlas 3D Reference Object Library  
> **Organización:** Human Reference Atlas (HRA) / HuBMAP Consortium (NIH Common Fund)  
> **Cita de la biblioteca:**  
> Heidi Schlehlein, Bruce W. Herr II, Ellen M. Quardokus, Andreas Bueckle, y Katy Börner. *HuBMAP CCF 3D Reference Object Library*. Disponible en: [https://humanatlas.io/3d-reference-library](https://humanatlas.io/3d-reference-library). Licencia CC BY 4.0.

## 5. Texto de Atribución Recomendado para la Aplicación (UI / About)

Cuando los modelos 3D se muestren en la interfaz de usuario (por ejemplo en el visor tridimensional del avatar de salud de la tripulación en `apps/crew-tablet` o `apps/ground-console`), se puede incluir el siguiente bloque de créditos:

```markdown
Modelos 3D anatómicos:
- Autores de los modelos 3D: Kristen Browne y Heidi Schlehlein (Human Reference Atlas / HuBMAP Consortium).
- Licencia: Creative Commons Attribution 4.0 International (CC BY 4.0).
- Fuente y repositorio: NIH 3D (3d.nih.gov) / Human Reference Atlas 3D Reference Object Library (humanatlas.io).
- Datos anatómicos base: Visible Human Project (U.S. National Library of Medicine) y Allen Human Reference Atlas (Allen Institute).
- Modificaciones: Optimización y conversión GLB para renderizado web en tiempo real dentro del proyecto LIGHTMINUTE.
```
