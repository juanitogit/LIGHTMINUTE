# ADR-004 — Stack
Motor **Python** (FastAPI, numpy/scipy, DuckDB) · UI **TypeScript** PWA (Vite+React o Next) · esquemas JSON Schema → tipos TS · despliegue Vercel + Render/Fly · modo demo con JSON precalculado. **Por qué:** velocidad con agentes de código, tests rápidos, científicos entienden Python. Alternativas: motor en TS (AURORA lo hizo; más trabajo de paridad).
