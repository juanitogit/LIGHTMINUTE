# Riesgos del proyecto
| Riesgo | Mitigación |
|---|---|
| Scope creep | MoSCoW + congelar T-4 h |
| Red/API caída | snapshots + `LLM_PROVIDER=none` + demo JSON |
| LLM alucina | verificador + plantillas |
| Claims inflados | validación honesta, etiquetas synthetic/proxy |
| Demasiado parecido a otros | foco en N-of-1, validación y Decision Cards |
| Percepción de proveedor del LLM | LLM opcional/intercambiable; datos sintéticos |
| Cansancio | dormir; turnos |
