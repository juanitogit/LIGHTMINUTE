# Pulido visual — plan para igualar/superar
**Regla:** estudiar patrones públicos, no copiar código/assets/marca. Los modelos anatómicos abiertos (BodyParts3D, HRA) se toman de su **fuente original** con atribución (verificar licencia allí).
1. Un solo visual héroe (SVG rápido o 3D decimado) → skill `visual-polish-playbook`.
2. Tokens únicos, oscuro por defecto, estados con icono+texto.
3. Vistas firma: tira de tripulación · Why · Act · Validación.
4. Datos reales del motor: `scripts/export_demo_json.py` → tu HTML (contrato en `docs/DEMO_DATA_CONTRACT.md`).
5. Estados reproducibles por URL para capturas y video.
