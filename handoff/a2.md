## DONE
- `services/engine/tether_engine/api/main.py` — FastAPI app with all five endpoints:
  `GET /api/health`, `GET /api/scenarios`, `GET /api/scenario/{name}`, `POST /api/card`,
  `GET /api/llm-stats` (+ `GET /`). CORS open for `localhost`/`127.0.0.1` any port and
  `Origin: null` (file:// prototypes); other origins get no CORS header.
- `llm/case_data.py` — scenario loading with the agreed order: `pipeline.run_scenario` →
  `public/data/scenario-<name>.json` → `public/demo-data.json` (marked `degraded: true`).
  Builds `EngineFacts` (level, confidence, numbers, indicators, confidence_inputs) from the
  engine's own day entry; no number is recomputed here.
- `llm/kb.py` — KB/evidence + thresholds + syndromes loaded and rendered into ONE
  byte-stable system prefix (sorted ids, no timestamps, no case data). `render_system_prefix()`
  is pure; `system_prefix()` caches it. PyYAML is used when present, otherwise a tiny
  built-in parser (no new dependency — `pyproject.toml` is A7's file).
- `llm/card_service.py` — `get_card(scenario, crew, day) -> {card, card_source, verifier_errors, usage}`
  (+ `provider`, `effort`, `attempts`). Effort `high` by default, `low` with `fast=True`
  (also `?fast=1` on the API). Verifier rejection ⇒ ONE retry with `verifier_errors` +
  `previous_attempt` appended to the **user** payload (prefix stays byte-identical) ⇒
  `protocols/templates.template_card` fallback. Transport/JSON error ⇒ immediate fallback.
  `LLM_PROVIDER=none` or no key ⇒ template only, no client is ever built.
- `llm/verifier.py` — hardened: frozen field set, dosing language, 140-char ground message,
  citation ids, diagnosis wording, numbers vs engine facts (1dp/2dp/integer forms), 1–5 steps.
- `llm/stats.py` — in-memory counters behind `/api/llm-stats`.
- `llm/redteam.py` — 30 adversarial cases (injection in symptom text, lower-urgency requests,
  diagnosis, fake citations, invented numbers, doses, schema smuggling, over-long ground
  message). Offline mode simulates a fully compromised model and asserts the verifier refuses.
  `python -m tether_engine.llm.redteam` (PYTHONPATH=services/engine) and `--live` for effort `max`.
- Tests: `tests/test_llm.py` (15), `tests/test_api.py` (10), extensions in

## INTERFACES I expose (stable, use these)
- `POST /api/card` body `{"scenario": "cmo_fever", "crew": "A", "day": 15, "fast": false}`
  → `{card, card_source: "llm"|"template", verifier_errors: [...], usage: {calls, prompt_tokens,
  completion_tokens, cache_hit_tokens}, provider, effort, attempts, scenario, crew, day, source, synthetic}`
  `card` always passes the verifier, so the UI can render it blindly.
- `GET /api/health` → `{status, llm_provider, llm_key_present (bool, never the key), llm_model,
  default_effort, fast_effort, card_fallback: "template", scenarios: [...], synthetic, not_a_medical_device}`
- `GET /api/scenarios` → `{scenarios: [{name, title, available, source}]}` (works before A1's files exist)
- `GET /api/scenario/{name}` → the contract JSON + `name`, `source`, `degraded`, `synthetic`
- `GET /api/llm-stats` → `{calls, llm_cards, template_cards, verifier_rejections, fallbacks, errors,
  prompt_tokens, completion_tokens, cache_hit_tokens, cache_hit_ratio, uptime_s}`

## KNOWN ISSUES
- **No live DeepSeek call has been executed** (no key in this environment). The LLM path is
  covered only by a fake client; the real request shape is untested against the API.
- `usage.cache_hit_tokens` reads `prompt_tokens_details.cached_tokens` — UNVERIFIED field name
  for DeepSeek. If it comes back empty, the cache still works; only the counter is wrong.
- The verifier rejects any field outside the frozen schema, so a chatty model will burn its one
  retry and land on the template. Watch `verifier_rejections`/`fallbacks` on the first live run.
- Headline/step word budgets (12/14 words) are NOT enforced by the verifier.
- `sep_sleep_loss` and `co2_creep` currently resolve to `demo-data.json` (`degraded: true`)
  because `public/data/scenario-*.json` do not exist yet.
- A scenario whose day entry has no resting-HR numbers returns 422 (no invented fallback number).
- No git repo/worktree existed when A2 started (`../tether-a2` impossible). Per the project
  owner's request I initialised the repo, pushed the scaffold to `main`
