## DONE

Crew tablet is a real Vite + React + TypeScript (strict) app in `apps/crew-tablet`.
`npm run build` is green (`tsc -b && vite build`).

- **Data layer** `src/lib/api.ts` — contract-first, API → static → demo:
  - `loadScenario(name)`: `GET /api/scenario/{name}` → `public/data/scenario-{name}.json`
    → `public/demo-data.json` (marks `degraded`).
  - `loadScenarioIndex()`: `/api/scenarios` → `public/data/scenario-index.json` →
    the three planned names.
  - `requestCard()`: `POST /api/card`, 15 s timeout, null on failure.
  - `/api/health` is probed first; if it fails the API path is disabled for that page
    load, so the static demo is immediate and the console stays clean.
  - Nothing is recomputed: every number, band, z, verdict and level comes from the payload.
- **Glance** — title + scenario brief from A1's `title`/`description`, crew strip with
  engine crew roles (CMO/CDR/MS1/MS2), level + one sentence + z + `learning`, crew
  attribution (uses the engine's `advice`, including “candidate … holding” wording),
  and an SVG body map whose regions glow from the personal verdicts and open the
  matching Why view.
- **Why** — indicator tabs for every indicator in the payload (6 in the current
  scenarios, including CO₂ and headache score) with units taken from the reading;
  personal 95% band chart with value line and baseline, and the Earth rule drawn
  from `earth_range` when A1 exports it or, failing that, from the cited
  `kb/thresholds.json` (band when both bounds exist, a single ceiling/floor line
  otherwise, labelled `earth-standard` or `demo parameter` with its source as a
  tooltip); y-axis never goes negative for non-negative signals; syndrome strip
  with alert line 2.33 (labelled demo parameter); three lens cards; loud banner for
  `hidden_in_range` / `expected_for_you` / `mixed`; confidence, `n_seen`, `z`, `p`,
  HRP risk family and hazard.
- **Act** — Decision Card: headline, what changed, why it matters, tappable
  checklist with progress, escalate-if, monitor chips, KB citations, `card_source`
  badge (verified DeepSeek vs protocol template), ground message with char budget and
  a simulated reply countdown from `routing` (`expected_reply_s`, `priority`,
  `send_now`, `act_onboard_first`).
- **A4 protocol runner mounted for real**: `vite.config.ts` exposes
  `virtual:tether-protocol-runner`, `virtual:tether-protocols` (inline
  `kb/protocols/*.json`) and `virtual:tether-protocol-css`; Act shows an optional
  protocol picker, shows the selected protocol's `trigger_patterns` (“When this
  protocol applies”) and mounts A4's `mountProtocolRunner`. Missing package = panel
  disappears, build stays green. Verified mounting and advancing a 9-step protocol.
- **Radiation / Validation** — tolerant renderers for `public/data/validation.json`,
  `public/data/radiation.json` and `/api/llm-stats`; honest empty states until A5

- **Shell** — URL hash state (`#scenario=&crew=&day=&ind=&view=&pres=1`) that resets

  dark default + light toggle, presentation mode, SYNTHETIC DATA + “not a medical

- **A11y/UX** — status = icon + text + colour; 44–48 px targets; native checkbox

## KNOWN ISSUES

- **Earth rule source**: A1 still exports no `earth_range`, so Why reads
  `kb/thresholds.json` at build time (`virtual:tether-thresholds`). That is the same
  cited rule the engine uses, shown with its own status (`earth-standard` vs
  `demo parameter`) and source, and CO₂/headache render as a ceiling only. When A1
  starts exporting `earth_range`, the payload wins automatically. `pvt_ms` has no
  cited Earth rule and says so.
- No scenario names a `protocol_id`, so A4's protocol panel starts at “No protocol”
  (the crew can pick one; nothing is auto-invented). The selected protocol now shows
  its `trigger_patterns` so the choice can be made from the card, not memory.
- A2/A1's template `ground_message` says “coordinated shift in HR/temp/sleep/PVT” even
  on `info` cards where nothing moved — reads like an alert on a Routine card. See
  requests.
- Card explanation is requested once per `scenario|crew|day` when Act opens; reload to
  retry.
- A4's protocol list is bundled at build time; adding a protocol needs a dev restart.
  In light theme A4's runner keeps its own dark surface.
- `apps/crew-tablet/dist/` is generated and **not committed**.
- This checkout is shared: when the first commit was made HEAD had been moved to
  `agent/a4`, so it was re-pointed to `agent/a3` (`agent/a4` restored to `972ea2b`).
