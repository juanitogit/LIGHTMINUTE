
Writes `apps/crew-tablet/public/data/scenario-<name>[-mild].json`,
`scenario-index.json`, `apps/crew-tablet/public/demo-data.json`
(`cmo_fever` strong: same crew/onset as before) and

## Interfaces I expose

- `run_scenario(name, seed=0, days=24, variant="strong")` with
  `name in {cmo_fever, sep_sleep_loss, co2_creep}`, `variant in {strong, mild}`.
  Deterministic by `(name, variant, seed, days)`.
- Fixed facts per scenario: `cmo_fever` onset day 15, affected `A` (CMO, Mars delay);
  `sep_sleep_loss` onset day 12, affected `C`, NOAA S1/S2; `co2_creep` onset day 8,
  all crew, shared exposure.
- `simulate.scenarios.SCENARIOS / generate / labels_for / write_scenario`.

## Additive fields (allowed by `docs/DEMO_DATA_CONTRACT.md`, announced here)

- top level: `scenario`, `title`, `description`, `variant`, `seed`, `delay_profile`,
  `onset_day`, `crew` (`{id: {role,label}}`)
- per day: `context` (`rest|eva|sleep_disrupted`), `hazards`
  (`solar_flux_pfu`, `s_scale`, `cabin_co2_ppm`), `qc` (`{dropped, total}`)
- `attribution.persistence` (`confirmed_days`, `required_days`) — crew-level mode is
  held at `none` until it repeats on 2 consecutive days; the affected list is that
  of the latest day.
- indicators: now 6 (`rest_hr`, `temp_c`, `sleep_h`, `pvt_ms`, `co2_ppm`,
  `headache_score`). A missing reading is simply absent for that crew-day; the
  syndrome fusion gives it zero evidence instead of reusing yesterday's value.

## Known issues / limits

- `mild` variants are deliberately weak: `cmo_fever` mild reaches `act` only on some
  seeds, `sep_sleep_loss` mild mostly stays at `watch`, `co2_creep` mild can spike
  for one crew member. Do not present mild as "detected".
- Sustained shifts are partly absorbed by the forgetting factor (`lam=0.98`), so an
  `act` can decay back to `watch` after ~5 days even while the stimulus persists.
  That is documented engine behaviour, not a bug — do not "fix" it in the UI by
  recomputing levels.
- `co2_creep` strong is a big shift (cabin 4200 ppm, ~+10 bpm, ~+100 ms PVT) so the
  shared path fires reliably across seeds 0-9. It is synthetic and labelled as such.
- `sep_sleep_loss` is a replay-shaped synthetic flux curve, not real GOES data.
- Scenario files are ~350 KB each (24 days x 6 indicators); the UI should still fall
  back to them when the API is down.
- `numpy`/`scipy` are required; on this machine the system Python is PEP-668 managed,
  so I used `project/.venv` (`python -m venv .venv && .venv/bin/pip install numpy scipy`).
